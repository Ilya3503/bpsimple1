# Robotic Perception & Manipulation System

Система машинного зрения для промышленного робота-манипулятора.  
Камера видит деталь → система определяет её положение → робот берёт деталь → кладёт в станок ЧПУ.

(`текущая актуальная ветка - resbranch`)

---

## Что умеет система прямо сейчас

- Снимает объёмную сцену глубинной камерой (облако точек — 870 000 точек за кадр)
- Объединяет снимки с нескольких ракурсов в одно облако для лучшей точности
- Автоматически находит объекты на столе: убирает фон, шум и поверхность стола
- Определяет положение и ориентацию каждого объекта в пространстве (6DoF pose)
- Сопоставляет найденный объект с CAD-моделью (алгоритм ICP)
- Формирует результат обработки (кластеры, позиция по каждому кластеру, ICP fitness) в файл position.json
- Запускает симуляцию: виртуальный робот берёт объект и переносит его в станок ЧПУ
- Управляется через веб-интерфейс (Swagger)

---

## Алгоритм работы системы (на данный момент)

```
Камера RealSense D415
        ↓
  Снимок с 2 ракурсов → объединение в одно облако
        ↓
  Фильтрация: убираем шум, фон, поверхность стола (RANSAC)
        ↓
  Кластеризация: каждый объект = отдельный кластер (DBSCAN)
        ↓
  Определение позы: сопоставление с CAD-моделью (ICP)
        ↓
  Вычисление точки захвата + обратная кинематика (ikpy)
        ↓
  Симуляция движения робота (PyBullet)
```

## Технологии

| Компонент | Что использует                                      |
|---|-----------------------------------------------------|
| Камера | Intel RealSense D415, библиотека `pyrealsense2`     |
| Обработка облака точек | `Open3D` — фильтрация, RANSAC, DBSCAN, ICP          |
| Определение позы | ICP (Iterative Closest Point) — сопоставление с CAD |
| Обратная кинематика | `ikpy` — вычисление углов суставов робота           |
| Симуляция | `PyBullet` — симуляция робота                       |
| Веб-сервер | `FastAPI` — REST API, Swagger UI                    |
| Платформа | NVIDIA Jetson (ARM, встроенный GPU)                 |

## Структура проекта

```
├── main.py                   # Веб-сервер, эндпоинты
├── app/
│   ├── camera.py             # Съёмка с камеры, фильтры RealSense
│   ├── processing.py         # Полный pipeline обработки облака точек
│   ├── merge.py              # Объединение снимков с разных ракурсов
│   └── viewer.py             # Веб-визуализация облаков точек в браузере
├── robot/
│   ├── controller.py         # Главная логика: восприятие → захват → симуляция
│   ├── grasp.py              # Вычисление позиции захвата
│   ├── kinematics.py         # Обратная кинематика (IK)
├── simulation/
│   └── bridge.py             # Управление PyBullet: сцена, робот, движение
├── scripts/
│   └── experiment_runner.py  # Автоматический подбор оптимальных параметров
├── cad_models/               # CAD-модели объектов в формате .ply
├── data/                     # Снимки облаков точек (.ply файлы)
└── results/                  # Результаты обработки, position.json
```

## Веб-интерфейс (Swagger UI)

Открыть: `http://[IP устройства]:8000/docs`  
Визуализация облаков: `http://[IP устройства]:8000/viewer`

| Эндпоинт | Действие |
|---|---|
| `GET /capture` | Сделать снимок с камеры |
| `POST /merge` | Объединить 2 последних снимка (2 ракурса) |
| `POST /process_pointcloud` | Обработать облако → найти объекты → `position.json` |
| `POST /execute` | Запустить симуляцию: робот берёт объект и кладёт в ЧПУ |
| `GET /viewer` | Открыть интерактивный 3D-просмотрщик облаков точек |

## Текущие задачи

**В работе сейчас и ближайшие планы**
- Улучшение качества изображений с камеры
- Проведение исследований для написания отчётности
- Тестирование системы с наваленными деталями, в сложных условиях
- Планирование архитектуры системы для перехода на следующий уровень

**Стратегическая цель**
- Переход на ROS 2 + NVIDIA Isaac ROS
- Интеграция open-source-модели от NVIDIA FoundationPose, которая будет выполнять оценку позиции объекта. Сейчас мы эту задачу решаем через ICP, использование модели позволит кратно повысить точность и даст системе возможность работать непрерывно
- Именно для перехода на ROS + FoundationPose нам нужен специалист в CV/ML. Эти технологии позволят очень быстро выдвинуть систему на высокий уровень
